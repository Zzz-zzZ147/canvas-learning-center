# 中文下载与安装说明

当前版本：**0.2.8 内测版**。

## 下载哪个文件

- macOS 中文默认版：`CanvasLearningCenter-0.2.8-macOS-universal-zh-CN-UNSIGNED-CANARY.pkg`
- Windows 中文默认版：`CanvasLearningCenter-0.2.8-Windows-x64-zh-CN-UNSIGNED-CANARY.msi`

英文默认版和中文默认版功能完全相同。安装后都可以通过右上角
`EN / 中文` 按钮随时切换语言。

请只从本仓库的 [GitHub Releases](https://github.com/Zzz-zzZ147/canvas-learning-center/releases/tag/v0.2.8)
下载，并对照 `SHA256SUMS.txt` 核对文件。

## 重要安全提示

0.2.8 文件名带有 `UNSIGNED-CANARY`，表示目前还没有 Apple 或 Microsoft
正式代码签名。macOS Gatekeeper 或 Windows SmartScreen 可能提示或阻止安装。
请先阅读英文主安装教程中的安全步骤；如果文件名或 SHA-256 不一致，不要打开。

## 连接 Canvas

1. 登录你自己的学校 Canvas。
2. 打开“账户 → 设置 → Approved Integrations”。
3. 创建用途为 `Canvas Learning Center` 的 Access Token，并设置合理的到期时间。
4. 只把 Token 粘贴到学习中心的首次设置界面。
5. 确认可访问课程后，开始第一次只读同步。

不要把 Token 发到邮件、评论区、聊天或 GitHub Issue。应用对 Canvas 只进行
只读访问，不会修改课程，也不会替你提交作业。

如果连接或同步失败，可在首次连接页或“系统状态”点击“导出到下载文件夹”，
再把生成的诊断 ZIP 私下发送给开发者。诊断包不包含 Token、姓名、课程正文、
笔记、提交、成绩、数据库、签名链接或本机路径。

## 资料自动更新与保存位置

- 打开桌面应用时，会检查 Canvas PPT、页面和模块是否需要增量更新。
- 如需在关闭主程序后继续检查，请到“系统状态”点击“启用主动提醒”，并批准
  操作系统权限；后台会确保资料至少每 24 小时刷新一次。
- macOS 课程资料：`~/Library/Application Support/com.zzz.canvas-learning-center/课程资料`
- macOS 个人归档：`~/Library/Application Support/com.zzz.canvas-learning-center/知识库`
- Windows 课程资料：`%LOCALAPPDATA%\ZZZ\CanvasLearningCenter\课程资料`
- Windows 个人归档：`%LOCALAPPDATA%\ZZZ\CanvasLearningCenter\知识库`

应用内会直接显示这些位置，并提供“在文件夹中打开”按钮。

## “知识结构待建立”是什么意思

它表示这个学习单元还没有可以用于进度和主动回忆的“已确认知识点”。0.2.8
会在资料同步完成后，尝试从本机已有的 PDF、HTML、PPTX 和文本资料自动建立
带来源定位的草稿。草稿需要你核对并确认后，才会纳入覆盖率、掌握率、首页推荐
和复习提醒。扫描型 PDF、外部链接、权限受限或正文不足时，应用会说明原因，不会
凭空生成答案。课程页也提供单元级“自动建立”按钮。

左下角“反馈与合作”和“系统状态 → 联系开发者”现在会打开同一个反馈窗口，
可选择默认邮箱、Gmail 网页版或复制邮箱地址。
