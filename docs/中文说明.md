# 中文下载与安装说明

当前版本：**0.2.4 内测版**。

## 下载哪个文件

- macOS 中文默认版：`CanvasLearningCenter-0.2.4-macOS-universal-zh-CN-UNSIGNED-CANARY.pkg`
- Windows 中文默认版：`CanvasLearningCenter-0.2.4-Windows-x64-zh-CN-UNSIGNED-CANARY.msi`

英文默认版和中文默认版功能完全相同。安装后都可以通过右上角
`EN / 中文` 按钮随时切换语言。

请只从本仓库的 [GitHub Releases](https://github.com/Zzz-zzZ147/canvas-learning-center/releases/tag/v0.2.4)
下载，并对照 `SHA256SUMS.txt` 核对文件。

## 重要安全提示

0.2.4 文件名带有 `UNSIGNED-CANARY`，表示目前还没有 Apple 或 Microsoft
正式代码签名。macOS Gatekeeper 或 Windows SmartScreen 可能提示或阻止安装。
请先阅读英文主安装教程中的安全步骤；如果文件名或 SHA-256 不一致，不要打开。

## 连接 Canvas

1. 登录你自己的学校 Canvas。
2. 打开“账户 → 设置 → Approved Integrations”。
3. 创建用途为 `Canvas Learning Center` 的 Access Token，并设置合理的到期时间。
4. 只把 Token 粘贴到学习中心的首次设置界面。
5. 确认可访问课程后，开始第一次只读同步。

不要把 Token 发到邮件、评论区、聊天或 GitHub Issue。应用对 Canvas 只进行
只读访问，不会修改课程，也不会替你提交作业。

如果连接或同步失败，可在首次连接页或“系统状态”点击“导出到下载文件夹”，
再把生成的诊断 ZIP 私下发送给开发者。诊断包不包含 Token、姓名、课程正文、
笔记、提交、成绩、数据库、签名链接或本机路径。
