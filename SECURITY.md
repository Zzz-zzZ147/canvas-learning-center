# Security

## Reporting a security or privacy issue

Do not open a public Issue if a report contains sensitive information.

Email **canvas-center@z-hstudio.com** with:

- the application version and operating system;
- a concise description of the issue;
- steps that reproduce the problem without real student data; and
- screenshots only after removing names, email addresses, student IDs, tokens,
  signed URLs, grades, comments, and course material.

Never send a Canvas Access Token, password, cookie, private key, or database.

## Supported version

The current supported public beta is `0.2.3`. This independent beta does not
operate a public bug-bounty programme.
